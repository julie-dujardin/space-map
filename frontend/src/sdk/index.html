spacemap SDK demos

Every page takes ?data=<export root> and ?lang=<bcp47>; on localhost the data is http://localhost:8080. Each puts its map on globalThis for the console.

all.html all four on one page

  • pick in the system map, and the other three follow; each has a Remount
  • ?body=naif-301 · ?nc=1

demo.html createMap

  • view: ?body= ?lat= ?lon= ?km=
  • clock: ?date=2030-01-01 ?live=0
  • input: ?interactive=0 · ?no=scrollZoom,bodySelect · ?coop=1
  • download: ?off=asteroids,comets · ?nc=1
  • scene settings: ?set=showClouds:0,showAtmospheres:0 · ?set=realisticLighting:1

flatmap.html createFlatMap

  • view: ?body= ?projection= ?lat= ?lon= ?zoom= · ?clip=60
  • layers and date: ?off=clouds,night ?date=2024-07-15
  • input: ?interactive=0 · ?no=scrollZoom · ?coop=1 · ?nc=1

panorama.html createPanorama

  • view: ?body= ?look=90,-10,60 · ?at=<panorama id>
  • limits: ?heading=-45,45 ?pitch=-20,20 ?fov=40,80
  • input: ?arrows=0 · ?follow=0 · ?interactive=0 · ?nc=1

systemmap.html createSystemMap

  • view: ?view=system:naif-699 · ?view=zone:inner · ?w=420
  • picking: ?grouping=systems ?zones=inner-outer · ?scope=mapped
  • the page's own: ?names=1 · ?places=1
